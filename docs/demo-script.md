# Demo script — Week 13 хамгаалалт (10–15 мин)

Баг бүрт 10–15 минут: тайлан танилцуулга (~8 мин) + Odoo demo (~5 мин). Demo-ийн дараалал:

1. **Login** → admin (0:30) — нэвтэрсэн дэлгэц, company "Shoppy.mn LLC"
2. **Apps** → суулгасан модулиуд харуулах (0:30) — eCommerce, Sales, Inventory, Project, Maintenance, Employees, Audit Log
3. **Asset register** → Maintenance→Equipment эсвэл Inventory жагсаалт (0:45) — "бидний 14 хөрөнгө энд бодитоор бүртгэгдсэн"
4. **Risk register** → Project "Risk Register" самбар (0:45) — нэг risk card нээж: threat/vuln/weakness/score
5. **RBAC** → Settings→Users & Companies→Groups: 5 бүлэг; **sales1**-ээр нэвтэрч зөвхөн өөрийн захиалга харагдахыг харуулах (1:30) — record rule ажиллаж байгааг баталгаажуулна
6. **Incident** → "Incident Response" самбар, нэг карт Incident→Close дамжуулна (0:45)
7. **Audit log** → auditlog дээр sale.order-ийн өөрчлөлтийн бичилт: хэн, хэзээ, юу өөрчилснийг нээх (0:45)
8. **SoA** → тайлангийн хүснэгт рүү буцах (0:15)

**Бэлдэх:** бусад хэрэглэгчийн session-уудыг incognito цонхоор нээлттэй байлгах (sales1 login шууд харуулахын тулд).
